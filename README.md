# Resource Landing Page 🌐📚🎵

This repository contains a beautifully designed, responsive, and mobile-optimized landing page that consolidates access to important personal and educational resources, including:

- Secure Documents (CryptPad, OneDrive)
- Study Materials (Books, Audiobooks, CEH Course)
- YouTube Playlists (Old Songs, Self-Help, Computer Science)
- Entertainment Resources

## 📁 Files Included

- `index.html` – Main HTML page with aesthetic background, icons, and responsive design
- `robots.txt` – Basic robots exclusion protocol file
- `README.md` – This readme file

## 🌟 Features

- Fully responsive layout (mobile-first design)
- Aesthetic nature-themed background
- Grouped and icon-tagged buttons for better UX
- No auto-redirects, all links open in the same tab

## 🚀 Live Preview

To preview the landing page, simply open `index.html` in any modern browser.
